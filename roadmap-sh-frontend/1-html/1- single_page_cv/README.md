# 📄 Single-Page CV

This repository contains a project developed for study and web development practice purposes.

The goal of this project is to create a simple curriculum vitae (CV) using only a single HTML page, without any frameworks or external libraries, focusing on the fundamentals of web page structure and semantic markup.

## 🎯 Objectives

Practice essential HTML concepts, including:

* Basic HTML document structure;
* Proper use of semantic HTML tags;
* Organizing information on a web page;
* Following markup best practices;
* Building an online resume using only HTML.

## 📚 About the Project

This project is based on a challenge provided by roadmap.sh, a platform that offers learning roadmaps and hands-on projects for various areas of technology.

The original project can be found here:

🔗 https://roadmap.sh/projects/single-page-cv
